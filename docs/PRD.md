# PRD — 취업 지원 현황 트래커

**Product Requirements Document**  
작성일: 2026-06-03  
작성자: 정주원

---

## 1. 배경 및 목적

### 문제
신입 개발자 취업 준비 중 원티드, 사람인, 그룹바이 등 여러 플랫폼에 동시 지원하다 보니:
- 어디에 지원했는지 기억이 안 남
- 연락이 왔을 때 어떤 공고인지 바로 못 찾음
- 현재 몇 개 진행 중인지, 탈락이 몇 개인지 파악이 안 됨

### 해결책
지원 내역을 한 곳에서 관리하는 간단한 웹 대시보드를 직접 만든다.

## 2. 타겟 사용자

- 본인 (정주원) — 개인용 도구
- 확장 가능성: 비슷한 상황의 취준생

## 3. 핵심 기능 (MVP)

### 3.1 지원 내역 추가
| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 회사명 | text | ✅ | 예: 카카오 |
| 포지션 | text | ✅ | 예: 백엔드 개발자 |
| 플랫폼 | select | ✅ | 원티드/사람인/그룹바이/링크드인/잡코리아/직접지원/기타 |
| 지원 날짜 | date | ✅ | 기본값: 오늘 |
| 상태 | select | ✅ | 서류중/서류합격/면접/최종합격/탈락 |
| 메모 | text | ❌ | 공고 링크, 담당자 이름 등 자유 기입 |

### 3.2 목록 조회
- 지원일 최신순 정렬
- 상태별 색상 구분 (뱃지)
- 탈락 항목은 회색으로 흐리게 표시

### 3.3 상태 변경
- 테이블에서 select로 바로 변경 (페이지 이동 없음)

### 3.4 상태 필터
- 상단 카드 클릭으로 해당 상태만 필터링
- 카드에 상태별 건수 표시

### 3.5 삭제
- 행 우측 삭제 버튼 → confirm 후 삭제

## 4. 비기능 요구사항

- **배포**: GitHub Pages (URL 있는 것)
- **인증 없음**: 개인용이므로 로그인 불필요
- **반응형**: 노트북/데스크탑 기준 (모바일 최적화는 이후)
- **빠른 완성**: 2~3주 내 MVP 완성

---

## 5. 상태 정의

| 상태 | 색상 | 의미 |
|------|------|------|
| 서류중 | 보라 | 지원 완료, 결과 대기 중 |
| 서류합격 | 파랑 | 서류 통과, 다음 단계 대기 |
| 면접 | 노랑 | 면접 일정 잡혔거나 완료 |
| 최종합격 | 초록 | 최종 합격 |
| 탈락 | 회색 | 서류/면접 탈락 |
