# 대시보드 구조 설명

## 화면 구성

```
┌─────────────────────────────────────────────┐
│  취업 지원 현황          총 N개 지원  [+ 지원 추가] │  ← 헤더
├─────────────────────────────────────────────┤
│  [서류중 3] [서류합격 1] [면접 2] [최종합격 0] [탈락 5] │  ← 상태 필터 카드
├─────────────────────────────────────────────┤
│  회사명  │ 포지션 │ 플랫폼 │ 지원일 │ 상태 │ 메모 │ 삭제 │  ← 테이블 헤더
│ ─────────────────────────────────────────── │
│  카카오  │ 백엔드 │ 원티드 │ 06-01 │[서류중]│ ... │  🗑  │
│  네이버  │ 프론트 │ 사람인 │ 05-30 │[면접]  │ ... │  🗑  │
└─────────────────────────────────────────────┘
```

---

## 컴포넌트 역할

### `App.tsx` — 메인 페이지
- Supabase에서 전체 지원 목록 불러옴
- 상태 필터 카드 렌더링 (클릭 시 필터 ON/OFF)
- 지원 목록 테이블 렌더링
- 상태 변경 / 삭제 처리

### `AddModal.tsx` — 지원 추가 모달
- "+ 지원 추가" 버튼 클릭 시 열림
- 폼 입력 후 제출 → Supabase에 INSERT
- 오버레이 클릭 또는 취소 버튼으로 닫힘

### `StatusBadge.tsx` — 상태 뱃지
- 상태에 따라 색상이 달라지는 select 드롭다운
- 변경 즉시 Supabase UPDATE

### `lib/supabase.ts` — DB 연결
- 환경변수로 Supabase 클라이언트 초기화

### `types/index.ts` — 공통 타입
- `Application` 인터페이스 (DB 행 타입)
- `Status` 타입 (유니온)
- `STATUS_COLOR`, `STATUS_LIST`, `PLATFORM_LIST` 상수

---

## 데이터 흐름

```
사용자 액션
    │
    ├─ 추가 → AddModal → supabase.insert() → fetchAll() → 상태 업데이트
    │
    ├─ 상태 변경 → select onChange → supabase.update() → 로컬 상태 업데이트
    │
    └─ 삭제 → confirm → supabase.delete() → 로컬 상태에서 제거
```
